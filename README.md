## ⚡ Key Features

- **🔨 Live Auctioneer Desk (`/`)**: Gavel hammer strikes (*Going Once*, *Going Twice*, *Hammer Sold!*), synchronized countdown clock, and quick-entry floor paddle bids for the 4 teams.
- **🙋 Team Bidder Cockpit**: 1-click team switcher between the 4 teams, +1x/+2x/+4x fast multiplier chips, squad quota tracking, and reserve purse solvency floor guards.
- **📺 4K Stadium Screen / Projector View**: Projector-ready broadcast view featuring live central stage, circular countdown timer, and a symmetrical 2x2 purse leaderboard for the 4 teams.
- **🔒 Hidden Governance Admin**: Press `Ctrl + Shift + S` or click the lock icon in the footer to access custom lot/team editing and tournament state export/import.
